# Retired runtime prompt rewriting

Retired by Cole on November 13, 2026. These patches and notes describe the old general runtime prompt interceptor. They are retained as historical source, outside the selected queue. No production loader, SDK adapter or generated workspace should import this folder.

The new upstream release changes authored BB Guide introduction text directly in its dedicated prompt patch. It does not rewrite interpolated messages or user bodies. The former organization Prompt Rules plugin is preserved separately under that repository’s tracked __archive/plugins/prompt-rules/.
